# MultiTool

All-in-one Windows toolkit written in **native C (Win32)** — one self-contained `multi-tool.exe` (~0.6 MB, no runtime, no DLLs).
Custom dark UI with anti-aliased graphics, live graphs and data tables.

*Bahasa Indonesia: [README.id.md](README.id.md)*

**Developed by Exter Interactive — ALIF HAKIM** · based on the Python MultiTool by Sobing4413.

## Highlights

| | |
|---|---|
| **Dashboard & Live Monitor** | CPU / RAM / disk / battery gauges, 2-minute graphs, network throughput, health score |
| **System info** | Full info, hardware summary, GPU, disks, SMART health, battery, uptime, users, health report |
| **Network** | IP, IP detail, adapters, ping & traceroute (native ICMP), DNS, WiFi on/off + saved passwords, speed test |
| **Security** | Security score, firewall, open ports with owning process, antivirus status, suspicious connections, accounts, privacy cleaner |
| **Malware Scan** | Heuristic scanner (EICAR, packers, double extensions, process masquerading, script obfuscation, digital signatures), quarantine, VirusTotal lookup, Microsoft Defender integration |
| **Driver Scanner** | SetupAPI inventory, outdated / generic / missing / unsigned / problem detection, **Windows Update driver lookup**, backup, CSV export |
| **Processes & Startup** | Process manager, startup manager, installed apps + uninstall |
| **Cleanup & Tools** | Temp/Recycle Bin cleaner, disk benchmark, large-files finder, app launcher, quick actions, hash calculator |
| **Power** | Timed shutdown / restart / sleep / hibernate, lock |
| **Settings** | 6 accent colors, 18 languages |

Full list: [docs/FEATURES.md](docs/FEATURES.md).

## Build

```bat
:: Visual Studio 2022
scripts\build_msvc.bat            :: or open multitool.sln -> Release | x64 -> Ctrl+Shift+B
:: MinGW-w64 (MSYS2)
make                              :: or scripts\build_mingw.bat
:: CMake
cmake -S . -B build && cmake --build build --config Release
```

Details and prerequisites: [docs/BUILDING.md](docs/BUILDING.md).

## Notes

* Some features need **Administrator** (WiFi on/off and passwords, Windows\Temp/Prefetch, SFC, driver backup). Use the *Standard user* chip in the sidebar to restart elevated.
* The malware scanner is heuristic and **complements — not replaces — a real antivirus**. Nothing is deleted automatically; quarantine is reversible.
* Test status: compiled with MinGW-w64 and exercised under Wine (all pages, ~35 features). Not yet tested on native Windows or compiled with MSVC.
